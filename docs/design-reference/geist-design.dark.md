# Geist 暗色设计系统参考样板

## 来源与说明

- **来源**:https://vercel.com/design.dark.md(Vercel Geist 设计系统暗色主题官方参考)。
- **性质**:本文是对来源的**忠实结构化摘要**,非逐字节原文复制;保留语义命名与具体 token 取值,删去冗余排版与示例代码。
- **定位**:它是 [`./geist-design.md`](./geist-design.md)(亮色主题参考)的**暗色对称版本**。两者共享同一套「语义 × 状态」结构骨架,只在「深浅映射」层不同——**换映射不换结构**。因此本文采取「对齐亮色、只突出差异」的写法:与亮色一致的章节仅给出结构骨架,差异点集中在「与亮色的差异」一节。

暗色相较亮色的总体取向:**更强调用颜色本身传达状态**(背景/边框态在暗色下对比天然偏弱,故状态变化主要靠色阶推进而非阴影/描边强化)。

## 与亮色的差异(本文重点)

这是阅读本文唯一需要重点关注的部分。其余结构请直接对照 [`./geist-design.md`](./geist-design.md)。

### 1. 阴影更重

暗色背景下需要更强的明度落差才能形成层级感,故阴影整体加重(亮色对应档位的 alpha 更低)。

| 用途 | 暗色阴影值 |
| --- | --- |
| 卡片 / Raised | `0 1px 2px rgba(0,0,0,0.16)` |
| 弹层 / 菜单 / Popover | `0 1px 1px rgba(0,0,0,0.02), 0 4px 8px -4px rgba(0,0,0,0.04), 0 16px 24px -8px rgba(0,0,0,0.06)` |
| 模态 / Dialog | 与弹层同结构,仅把中/外层偏移档位提升到 `8px` 与 `24px`(`0 1px 1px ...` 不变,后两档改用 `8px` / `24px` 偏移) |

> 模态与弹层**同结构**,仅把中间/外层档位的偏移从 `4px`/`16px` 提升到 `8px`/`24px`,以表达更高的抬升层级。

### 2. 聚焦环:blue-900

- **暗色**:`2px` 间隙 + `2px` **blue-900** 环。
- **亮色**:同样是 `2px` 间隙 + `2px` 环,但环色用 **blue-700**。

差异本质:聚焦环结构不变,只是把环色从亮色色阶解析到暗色色阶(blue-700 → blue-900),以保证在暗背景上的可见度。

### 3. 暗色优先用颜色传达状态

暗色下背景态(100–300)与边框态(400–600)的明度差较小,因此**状态表达更依赖色阶推进**:悬停/按下主要通过沿色阶上移来体现,而非依赖更强的描边或阴影。这是暗色与亮色在「同一套状态规则」下的实际侧重差异。

## 与亮色一致的结构(骨架对照,不展开)

以下各项**取值与亮色完全相同**,深浅差异已由「色阶映射」吸收,此处仅列骨架以备查,不重复亮色文档的详细说明。

### 颜色:色阶意图(100–1000)

与亮色一致,语义按 intent 递进:

- **100–300**:背景态(默认 / 悬停 / 激活背景)
- **400–600**:边框态(默认 / 悬停 / 激活边框)
- **700–800**:实心填充(高对比 / 悬停)
- **900–1000**:文字与图标(次要 / 主要)
- 另含 **gray-alpha** 半透明 token,用于边框、分割线与遮罩。

### 排版

四类家族,与亮色相同:`heading-*`、`label-*`、`copy-*`、`button-*`;各含字体、字号、字重、行高、字距;`-mono` 变体使用 Geist Mono。

### 间距

4px 基准;三段节奏与亮色一致:组内 `8px` / 组间 `16px` / 区块间 `32–40px`。

### 圆角

`6px`(常规表面)/ `12px`(菜单、模态)/ `16px`(全屏表面)/ `9999px`(胶囊、圆形控件),与亮色相同。

### 动效

时长 `150ms`(状态变化)/ `200ms`(弹层、tooltip)/ `300ms`(遮罩、模态);缓动 `cubic-bezier(0.175, 0.885, 0.32, 1.1)`;尊重 `prefers-reduced-motion`。均与亮色相同。

### 组件交互状态

与亮色一致:**悬停 +1 档 / 按下 +2 档 / 禁用 / 聚焦**。区别仅在于颜色解析到暗色色阶(参见上文「聚焦环」与「优先用颜色传达状态」)。

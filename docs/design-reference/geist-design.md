# Geist 亮色设计系统参考样板

## 来源与说明

- 来源:https://vercel.com/design.md(Vercel 官方域名下的 Geist 设计规范页,亮色主题;即本任务截图所示链接)。
- 本文为 Geist 亮色设计系统的结构化摘要,保留全部具体数值与意图编码规则,非逐字节原文。
- 用途:作为「船长 App」设计体系的对标样板,供团队在颜色、排版、间距、组件状态等维度做横向对照与取舍。
- 范围:本文只覆盖 Geist 亮色主题;暗色版另见文末链接。

## 概览

- 主题:Geist(Vercel 设计系统)亮色主题。
- 理念:minimal & high-contrast——大量留白、克制用色、内容置于近中性表面。
- 核心原则:颜色用于传达状态而非装饰;实色高对比只留给状态与主操作;信息层级优先用灰阶表达。

## 颜色与状态色阶

### 基础色

| 角色 | 值 |
| --- | --- |
| 主色 (primary) | `#171717` |
| 次色 (secondary) | `#4d4d4d` |
| 强调蓝 (accent) | `#006bff` |
| 背景 100 | `#ffffff` |
| 背景 200 | `#fafafa` |

### 色阶与意图编码

每个非背景色都有 `100 → 1000` 共 10 档,按意图(而非单纯明暗)编码:

| 档位区间 | 意图 | 细分 |
| --- | --- | --- |
| 100–300 | 背景态 | 默认 / 悬停 / 按下 |
| 400–600 | 边框态 | 默认 / 悬停 / 按下 |
| 700–800 | 实心填充态 | — |
| 900–1000 | 文字与图标层级 | 次 / 主 |

- 色板:`gray` / `blue` / `red` / `amber` / `green` / `teal` / `purple` / `pink`。
- 每个色值同时提供 sRGB hex 与 Display P3 的 `oklch()` 等值。

## 排版

字体家族:

- Geist Sans——UI 与正文。
- Geist Mono——代码 / 数据 / 等宽数字。

四类排版各自成阶,职责与参数如下:

| 类别 | 阶梯 | 字重 | 特征 |
| --- | --- | --- | --- |
| Headings | `heading-72 … heading-14` | 600 | 字距收紧 |
| Labels | `label-20 … label-12` | 400 | 单行、可扫读 |
| Copy | `copy-24 … copy-13` | 400 | 更高行高,承载多行正文 |
| Buttons | `button-16 … button-12` | 500 | 紧凑控件 |

提示:`copy-14` 与 `label-14` 覆盖大多数文本场景,作为默认起点。

## 间距与布局

- 基准:4px。
- 间距阶梯:`4 / 8 / 12 / 16 / 24 / 32 / 40 / 64 / 96`。
- 三段节奏:
  - 组内:8
  - 组间:16
  - 区块间:32–40
- 卡片内边距:默认 24,紧凑 16,英雄区 32。

断点:

| 名称 | 值 (px) |
| --- | --- |
| sm | 401 |
| md | 601 |
| lg | 961 |
| xl | 1200 |
| 2xl | 1400 |

- 中栏宽度:1200。

## 阴影(亮色)

| 层级 | 阴影值 |
| --- | --- |
| 卡片 | `0 2px 2px rgba(0,0,0,0.04)` |
| 弹层 / 菜单 | `0 1px 1px rgba(0,0,0,0.02), 0 4px 8px -4px rgba(0,0,0,0.04), 0 16px 24px -8px rgba(0,0,0,0.06)` |
| 模态 | `0 1px 1px rgba(0,0,0,0.02), 0 8px 16px -4px rgba(0,0,0,0.04), 0 24px 32px -8px rgba(0,0,0,0.06)` |

## 动效

- 使用原则:仅在说明变化时使用动效,绝不为装饰;多数交互即时(0ms)。
- 缓动曲线:`cubic-bezier(0.175, 0.885, 0.32, 1.1)`。
- 时长:
  - 状态:150ms
  - 弹层:200ms
  - 遮罩:300ms
- 无障碍:尊重 `prefers-reduced-motion`。

## 圆角

| 值 | 适用 |
| --- | --- |
| 6px | 日常表面与控件 |
| 12px | 菜单与模态 |
| 16px | 全屏表面 |

## 组件与状态

### 按钮

| 类型 | 填充 | 文字 / 边框 |
| --- | --- | --- |
| Primary | `gray-1000` 填充 | `background-100` 文字 |
| Secondary | `background-100` 填充 | 半透明 `gray-alpha-400` 边框 |

### 输入框

- 填充:`background-100`。
- 边框:半透明。
- 圆角:6px。
- 文本 token:`label-14`。

### 尺寸

| 尺寸 | 高度 (px) |
| --- | --- |
| 小 | 32 |
| 中(默认) | 40 |
| 大 | 48 |

### 交互状态

| 状态 | 规则 |
| --- | --- |
| 悬停 | 色阶 +1 档 |
| 按下 | 色阶 +2 档 |
| 禁用 | `gray-100` 填充 + `gray-700` 文字 |
| 聚焦 | 双环:2px 白色间隙 + 2px `blue-700` 环 |

## 文案与 voice

- 大小写:
  - 标签 / 按钮 / 标题 / Tab 用 **Title Case**。
  - 正文 / 辅助文本用 **sentence case**。
- 动作文案:动词 + 名词(如 `Deploy Project`)。
- 错误信息:说清「发生了什么 + 怎么办」。
- Toast:命名具体变化,不使用「successfully」。
- 空态:指向首个可执行动作。
- 进行态:用现在分词 + 省略号(如 `Deploying…`)。
- 排版细节:使用真正的数字、弯引号、省略号字符;去掉「please」与营销腔。

## Do 与 Don't

### Do

- 用灰阶给信息分级:`1000` 主 / `900` 次 / `700` 禁用。
- 强调实色只留给状态与主操作。
- 正文对比度 ≥ 4.5:1。
- 所有可交互元素显示聚焦环。
- 一致套用排版 token。

### Don't

- 不要只用颜色传达状态。
- 不要把 `background-200` 当通用填充。
- 不要在同一视图混用圆角与直角。
- 不要拿 `gray-*` 顶替 `background-*`。

## 如何使用这份样板

1. 先读方法论:[设计逻辑方法论(基于 Geist 抽象)](../2026-06-25-设计逻辑方法论-基于Geist抽象.md),理解从 Geist 抽象出的设计决策框架。
2. 再对照落地建议:[船长 App 设计一致性与排版优化建议](../2026-06-25-船长App设计一致性与排版优化建议.md),把本样板的数值与规则映射到船长 App 的具体页面。
3. 暗色场景参照:[Geist 暗色设计系统参考样板](./geist-design.dark.md),与本文配套使用,确保明暗两套表面、阴影与状态色阶一致对应。

使用要点:本样板是「对标基准」而非「照搬清单」——优先迁移意图编码规则(色阶意图、灰阶分级、状态 +1/+2 档、实色留给状态)与排版/间距 token 体系,具体数值需结合船长 App 的原生 Android 实现与中文排版习惯做本地化校准。

# 语音记事本

首页九宫格新增「语音记事本」。兼容项目现有的 Android Java / minSdk 21，使用 Vosk 本机推理，不依赖系统语音服务或云端转写。

## 首次使用

1. 点击「下载中文模型」，浏览器下载官方 [vosk-model-small-cn-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip)。也可以在其他设备下载后传到手机。
2. 回到记事本，点击「导入模型 ZIP」，选择下载的 ZIP，**不用自行解压**。模型解压到应用私有的 no-backup 目录，后台校验成功后启用录音。
3. 允许麦克风权限后，按住录音按钮说话。松开后等待尾句识别完成，在预览中修正文字，点击「确认」才追加到当前笔记并写入本机 SQLite；点击「取消」丢弃本次录音，原笔记不变。空结果可以手动补充或取消。
4. 手动输入正文仍会自动保存。点击「完成 / 新建」结束当前草稿并开始下一条。待确认期间不能切换笔记、分享、删除、完成原稿或再次录音；先确认或取消本次录音。
5. 点击笔记可编辑、分享或删除；点击日期标题分享当天汇总。在 Android 分享面板中选择**飞书**，再选会话并确认发送。

模型只需导入一次。之后打开飞行模式仍可录音转文字、查看、编辑和保存。分享给飞书需要已安装支持文本接收的飞书客户端；消息的实际发送由飞书完成，通常需要联网。当前没有机器人 webhook、飞书云文档写入、自动发送或内置账号授权。

## 方案选择与边界

- 固定依赖 `com.alphacephei:vosk-android:0.3.75@aar`、`net.java.dev.jna:jna:5.13.0@aar`。当前 AGP 4.1.3 / D8 2.1.86 在处理 JNA 5.18.1 的 `CallbackReference$DefaultCallbackProxy` 时发生空指针错误；仅将 JNA 调整为 5.13.0 后 Release 构建通过，保留现有工具链。构建通过不代表真实麦克风、模型推理或各 Android 版本兼容性已经验收。
- 官方中文小模型约 **42 MB 下载大小**，Apache 2.0，定位 Android / Raspberry Pi。解压大小及运行内存高于下载体积，需预留空间；此实现限制解压总量 256 MiB、文件数量 4096。
- 在此旧版 Android Java 项目中，Vosk 的 Maven AAR、流式 PCM 识别和轻量中文模型带来的接入成本较低。Sherpa-ONNX / SenseVoice 等是可评估的替代方案；本实现没有跨设备准确率/延迟对比数据，不声称 Vosk 是所有场景中的最佳识别器。
- 模型不打入 APK，避免给每次应用安装/更新附加 42 MB 模型；首次识别前需要明确导入。这里没有联网自动下载逻辑，也不会自动退回云端识别。
- 小模型对普通话更适合，方言、背景噪声、专业词语可能有识别错误。输出为原始文字，未增加自动标点、音频文件保存、说话人分离或翻译。
- 录音使用 16 kHz / mono / PCM16；退出页面、旋转或进入后台会停止录音，不在后台持续采集。唯一应用级会话继续接收尾句并保留待确认文字，模型关闭后也不清除候选；同一进程内重入恢复预览。模型与识别器在串行工作线程处理并释放；UI 不做模型解压或推理。
- 正式草稿按固定 UUID 更新。识别回调只修改进程内临时片段，不写正式笔记或持久化候选；确认时只追加一次，保留原笔记 UUID 和归档日期。确认保存失败时原正文不变，候选仍可修改、重试或取消；重试不会重复追加。取消后排空的迟到回调不会进入正文。
- 已确认文字和手动输入的草稿存于 SQLite，草稿指针保存到 SharedPreferences，重开可继续编辑。**未确认录音只保留在当前进程内；进程被杀后不恢复。** 未产生识别回调的音频也无法恢复。
- 日期使用笔记**首次产生非空文字时**的本地日期；编辑或切换时区不改变原归档日期。跨午夜的一条笔记仍属于创建日。
- SQLite 存在应用私有目录；Android 全量备份规则排除笔记数据库和草稿指针，模型在 no-backup 目录。数据库未额外加密。卸载应用或清除应用数据会删除这些内容。
- ZIP 导入拒绝越界路径、过多条目、过大的解压输出和不完整模型；真正的 Vosk 加载成功才安装。下载动作仅打开浏览器，识别引擎不发送音频或笔记。

## 验证

在仓库根目录运行：

```sh
bash tests/voice/run.sh
```

该脚本需要 JDK 9+ 和 Python 3。核心检查覆盖 partial 替换/final 合并/空回调保留、日期边界、分享文本，以及正常模型 ZIP、越界路径、缺失模型、多模型、条目数量和解压体积限制。可用空间不足 320 MiB 时明确跳过 256 MiB 解压上限用例，不把磁盘写满误判为通过。

会话回归使用真实 `VoiceNotebookSession`，以测试替身替换 Android、识别引擎和数据库 IO，检查片段确认前不落库、取消与迟到回调、尾句排空后编辑、重复确认、确认保存失败及重试、原笔记身份保留、旋转快速重入、模拟新进程 owner 不恢复候选，以及既有手动输入、读写故障和文件选择器返回路径。它不验证真实 SQLite、麦克风、native 识别质量，也不替代 APK 构建或真机测试。

APK 构建沿用当前仓库的 Gradle wrapper、Android Gradle Plugin 与 SDK 配置，不通过本功能升级工具链。

```sh
bash gradlew :captain:assembleDebug
```

真机验收：

1. 初次无模型时只能输入文字；取消选择或导入损坏 ZIP 后可再次导入。
2. 导入中文模型后断网，授权麦克风，按住按钮连续说两句话并停顿，松开后等待尾句并修改预览；确认前原稿和日期列表不变，确认后只追加一次。再录一段并取消，原稿不变。
3. 编辑文字、完成新建两条，杀掉进程重开；笔记仍在对应日期，草稿可恢复。
4. 录音中退后台、离页或旋转；麦克风停止，返回后恢复待确认预览。待确认时杀掉进程重开，候选不恢复，已保存原稿保留。
5. 拒绝麦克风权限、麦克风被占用、存储空间不足：页面有明确错误，原稿不变；已识别候选可修改或取消，确认保存失败后释放空间可重试且不会重复追加。
6. 分享单条和当天汇总到飞书；飞书收到日期和文字；没有安装飞书时可选择其他文本分享应用。
7. 删除需确认，取消不删除；修改旧笔记仍归档到原日期。

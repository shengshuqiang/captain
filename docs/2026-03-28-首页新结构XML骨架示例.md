### 4.2 RecyclerView 适配器

```java
public class FeatureCardAdapter extends RecyclerView.Adapter<FeatureCardAdapter.ViewHolder> {

    private List<FeatureCardData> features;
    private Context context;

    public FeatureCardAdapter(Context context, List<FeatureCardData> features) {
        this.context = context;
        this.features = features;
    }

    @Override
    public ViewHolder onCreateViewHolder(ViewGroup parent, int viewType) {
        View view = LayoutInflater.from(parent.getContext())
            .inflate(R.layout.item_feature_card, parent, false);
        return new ViewHolder(view);
    }

    @Override
    public void onBindViewHolder(ViewHolder holder, int position) {
        FeatureCardData feature = features.get(position);

        holder.icon.setImageResource(feature.getIconResId());
        holder.title.setText(feature.getTitle());
        holder.description.setText(feature.getDescription());

        // 设置 badge
        if (feature.getBadge() != null && !feature.getBadge().isEmpty()) {
            holder.badge.setText(feature.getBadge());
            holder.badge.setVisibility(View.VISIBLE);
        } else {
            holder.badge.setVisibility(View.GONE);
        }

        // 点击事件
        holder.itemView.setOnClickListener(v -> {
            context.startActivity(feature.getIntent());
        });
    }

    @Override
    public int getItemCount() {
        return features.size();
    }

    static class ViewHolder extends RecyclerView.ViewHolder {
        ImageView icon;
        TextView title;
        TextView description;
        TextView badge;

        ViewHolder(View itemView) {
            super(itemView);
            icon = itemView.findViewById(R.id.feature_icon);
            title = itemView.findViewById(R.id.feature_title);
            description = itemView.findViewById(R.id.feature_description);
            badge = itemView.findViewById(R.id.feature_badge);
        }
    }
}
```

### 4.3 Activity 初始化

```java
public class MainShopTabView extends Fragment {

    private RecyclerView featureCardsRecycler;
    private FeatureCardAdapter adapter;

    @Override
    public View onCreateView(LayoutInflater inflater, ViewGroup container, Bundle savedInstanceState) {
        View view = inflater.inflate(R.layout.main_shop_tab_layout_new, container, false);

        featureCardsRecycler = view.findViewById(R.id.feature_cards_recycler);

        // 设置 GridLayoutManager (2列)
        GridLayoutManager layoutManager = new GridLayoutManager(getContext(), 2);
        featureCardsRecycler.setLayoutManager(layoutManager);

        // 准备数据
        List<FeatureCardData> features = prepareFeatureData();

        // 设置适配器
        adapter = new FeatureCardAdapter(getContext(), features);
        featureCardsRecycler.setAdapter(adapter);

        return view;
    }

    private List<FeatureCardData> prepareFeatureData() {
        List<FeatureCardData> features = new ArrayList<>();

        features.add(new FeatureCardData(
            R.drawable.ic_qr_code,
            "信息二维码",
            "保存和读取重要信息",
            new Intent(getContext(), QRActivity.class)
        ));

        features.add(new FeatureCardData(
            R.drawable.ic_web_sniffing,
            "资源嗅探",
            "提取并保存网页资源",
            new Intent(getContext(), WebSniffingActivity.class)
        ));

        // 添加更多功能...

        return features;
    }
}
```

## 6. 注意事项

### 6.1 必须遵守的规则

- ✅ 使用 token 颜色，不硬编码
- ✅ 使用 `sp` 字号，不使用 `dp`
- ✅ 卡片标题最多 1 行
- ✅ 卡片说明最多 2 行
- ✅ 推荐区默认隐藏，仅在有真实依据时显示

### 6.2 禁止行为

- ❌ 不要为了"丰富页面"添加伪内容
- ❌ 不要回退到九宫格布局
- ❌ 不要使用硬编码颜色
- ❌ 不要压缩卡片间距

## 7. 验收标准

- [ ] 欢迎区使用渐变背景
- [ ] 功能卡片使用 2 列布局
- [ ] 卡片圆角为 20dp

## 8. 总结

这个新结构将首页从"九宫格工具页"升级为"有氛围、有主次、有品牌感的轻工具首页"。关键是：

1. **欢迎区**提供品牌氛围
2. **功能卡片区**提供清晰的功能入口
3. **推荐区**仅在有真实依据时显示
4. **所有资源**使用 token，确保一致性
